# ADR-019: 赋值语义 — 复制 value 与绑定例外

- 状态: 已接受 (2026-11-02)
- 决策者: aserjoker（项目负责人） + CodeAgent
- 关联: ADR-013（闭包与作用域）、ADR-015（Value 内存模型）

## 背景

确定赋值操作（属性赋值、变量声明、传参）的底层语义。

## 决策

### 1. 核心规则：除闭包/import 外，其它所有情况都是复制 value

- **闭包捕获 / import 导入**：多个作用域绑定同一个变量（共享存储槽）——
  唯一例外，是**绑定**，修改一处多处可见。
- **其它所有情况都是复制 value**：
  - 属性赋值 `a.b = c`：复制一个 c，在 a 中加入名为 b、值为「clone c」的属性。
  - 变量声明 `let x = c`。
  - 函数传参。
  - 等。

### 2. 复杂对象的复制 = 共享 data

- 复杂对象（Object/Function/Array）的复制：
  创建新 value，**共享同一个 data**（data.ref++）。
- 从而 value 共享 → data 引用共享 → **引用语义成立**。

### 3. 浅复制（轻量）

- 复制 value 是**浅复制**：
  - 简单值：直接拷贝数据。
  - 复杂对象：共享 data（ref++），不深拷贝属性。

### 4. 字符串等不可变类型：共享 data

- 字符串复制也是**共享 data**（不可变，ref++），与复杂对象一致。

## 与 Value 内存模型的关系（ADR-015）

- 复制复杂对象 = 新 value 指向同一 data → data.ref++ → 引用语义成立。
- 复制字符串 = 共享不可变 data → ref++。

## 两层共享模型（精确版）

共享只发生在两个层，必须分清楚：

```
第一层：多个 scope 引用同一个 value
  └── 仅发生在：import 导入 / 闭包捕获（多个作用域绑定同一个变量/存储槽）

第二层：多个 value 引用同一个 data
  └── 仅发生在：复杂对象（复制/传参时新 value 共享 data，ref++）
               不可变类型（字符串，共享 data）
```

- **不存在**「多个 value 引用同一个 value」——无法表达，也无需表达。
- **bind 是复制 FunctionData（独立 data）**，不属于共享（见 ADR-021）。
- 复制 value 是浅复制：简单值拷贝数据；复杂对象/字符串共享 data。

## 统一模型

```
一切皆复制（value 层）：
  简单值 → 拷贝数据
  复杂对象 → 共享 data（引用，第二层共享）
  字符串 → 共享 data（不可变，第二层共享）
  bind → 复制 FunctionData（独立 data）

闭包/import = 第一层共享（多个 scope 绑定同一 value），唯一例外，不复制
```

## 后果

- 优点：模型统一优雅（一切皆复制，复杂类型靠共享 data 实现引用）；
  与 data.ref 计数天然衔接；引用语义正确。
- 缺点：需明确区分「复制 value」与「绑定变量」两种操作。
